# natura-local-media

Allotjament temporal de fitxers (vídeos i imatges) perquè Metricool en faci la còpia en programar les publicacions de Natura Local.

- Els fitxers s'hi pugen just abans de crear l'esborrany a Metricool i **s'esborren** quan la publicació ja s'ha fet.
- Res d'aquí és una publicació: cada peça la valida Toribio abans de programar-la (D-012).
- Origen: `CLAUDE CODE/xarxes-youtube/peces/` del repositori de treball.
